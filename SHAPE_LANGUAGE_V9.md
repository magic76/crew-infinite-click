# Shape Language v9

Goal: remove the "everything is a circle" look without changing the v8 promise-chain gameplay.

Changes:
- Main target now has a different silhouette per world: petals/seed, lightning, torn leaf, crystal, void slit, digital tile.
- PromiseRuntime uses angular tears, shards, modular fragments, creature silhouettes, star transforms, duplicated glyph blocks and seams. It contains no Pixi circle drawing.
- Static backgrounds now use vines/leaves, storm slabs, branches, crystals, perspective void polygons and neon grid blocks.
- WorldMutation large forms and scars use leaves, polygons, crystals and perspective shards; circles remain only for short-lived impact rings.
- Decoys inherit the current world's shape language instead of rendering as white circles.
- No gameplay/FOMO timing changes from v8.
