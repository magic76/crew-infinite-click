# Asset Art Pass v17

## Goal
Lift visual quality without changing the core v15/v16 toy-box gameplay.

## Main changes
- removed heavy oversized ring overlays and reduced ripple density
- cleaned background into a calmer premium toy-box stage
- redrew bumper / gift / balloon / spring toward a more collectible-toy look
- softened camera tilt and flash so hits feel expensive instead of messy
- improved pet grounding via lighter motion-aware shadows
- slightly reduced the starting hero overscale

## Expected result
The scene should read cleaner and more premium: the pets remain the stars, hit FX feel shorter and brighter, and objects no longer look like raw classroom-demo geometry.
