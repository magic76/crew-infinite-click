# ENDLESS_CHAOS_V27

Turns the toy-box loop into an endless stage run.

- Timed/progress hybrid stages that flow automatically into the next stage.
- Every fifth stage is a MEGA STAGE.
- Deterministic stage recipes combine weapon, world, pet, object, and climax modifiers.
- Weapons: MULTISHOT, RICOCHET, RAPID, LIGHTNING.
- World rules: LOW_GRAVITY, STORM, BUBBLE_RAIN, CARNIVAL_FRENZY.
- Pet rules: GIANT, MINI_SWARM, FAST, BOUNCY.
- Object rules: BUMPER_RUSH, BALLOON_STORM, SPRING_PARTY, GIFT_FEVER.
- Climax events escalate into THUNDER_FINALE, PINBALL_BREAK, WORLD_BREAK, OVERDRIVE_RAIN, and REALITY_BREAK.
- CHAOS multiplier rises while the player keeps pressing/hitting, affects button power, and can trigger an early Reality Break.
- Persistent HUD shows stage, recipe, timer, progress, and CHAOS multiplier.
- No Game Over: stages continuously roll forward.

Version: `0.56.0-endless-chaos-v27` / versionCode `405`.
