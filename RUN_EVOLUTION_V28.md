# RUN_EVOLUTION_V28

v28 turns the endless run into a visible power-growth arc instead of rotating weapon recipes.

## Weapon evolution

Unlocks stack for the rest of the run:

- Stage 1: Single shot
- Stage 3: Double shot
- Stage 5: Spread shot
- Stage 8: Ricochet
- Stage 12: Chain Lightning
- Stage 15: Missile Rain

Later stages keep all previous powers, so one press can trigger a volley, ricochet chain, lightning, and missile follow-up together.

## Stage cadence

- Every 5th stage remains a MEGA STAGE.
- Every 10th stage is a BOSS STAGE.
- Boss stages show a large target, dedicated health bar, visible crack phases, hit flash feedback, and a destructive boss-break climax.
- Boss archetypes rotate with the world: Giant Toy, Crystal Core, Super Balloon, and World Core.

## CHAOS weapon thresholds

CHAOS now changes weapon behavior directly:

- x10: Double Fire
- x20: Big Shots
- x30: Ricochet
- x50: Chain Lightning
- x75: Auto Barrage while holding
- x100: Reality Break

## Scope

This release intentionally focuses on progression and payoff. Rare Jackpot Events and destructible world scenes are left for the next iteration so they can build on top of the new run-growth spine instead of being mixed into the same change.
